# R1 Task Catalog

## How to dispatch and close a task

Every task below is independently dispatchable only after its dependencies have durable evidence. “Files” are expected ownership areas, not permission to bypass shared-file reservations. Each verification row explicitly states backend (`B`), frontend (`F`), and browser end-to-end (`E2E`) expectations; `N/A` means no meaningful test in that layer and gives the substitute evidence. A task closes only when its acceptance IDs and linked normative requirements pass, security and documentation impacts are handled, and the evidence bundle follows `delivery-evidence-template.md`.
