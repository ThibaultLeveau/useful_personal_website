# Documentation walkthroughs

The following repository paths were reviewed as the entry points for release users:

- site owner: `docs/user/README.md`, first login, site configuration, pages, projects, blog, media,
  contact inbox, API tokens, audit, and system health;
- API consumer: `docs/api/README.md`, conventions, authentication, catalogs, each resource guide,
  audit, contacts, media, and token scopes;
- contributor: root `README.md`, `CONTRIBUTING.md`, `docs/development/README.md`, local development,
  testing, generated client, database/migrations, design system, and release process;
- operator: configuration, containers, security architecture, deployment topology, media operations,
  contact retention, audit retention, and token key rotation.

Automated repository checks validate documentation links. The final production walkthrough remains
blocked on legal copy, hostname, storage, retention, and recovery values. The maintainer later
selected and installed the MIT License during M14.
