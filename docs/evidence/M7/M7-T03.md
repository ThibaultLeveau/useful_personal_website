# M7-T03 - Integrated blog lifecycle certification

## Decision

Pass for the M7 blog vertical slice on 2026-08-04. An administrator can create and validate
controlled source, maintain taxonomy and related posts, preview privately, export exact normalized
Markdown, publish now or schedule, preserve a frozen live revision while editing, republish,
reschedule, hide/show, unpublish, reorder, and soft-delete. Visitors receive only effective frozen
allow-listed content, relations, facets, metadata, JSON-LD, and sitemap entries.

## Privacy and final-state inspection

Every successful E2E journey deletes its own synthetic post. Two earlier synthetic browser proofs
left by aborted corrective runs were identified by their `Blog proof` titles and soft-deleted
through authenticated APIs with current ETags. The anonymous list now returns zero items/total.
Public API, SSR HTML, metadata, JSON-LD, sitemap, screenshots, reports, and logs contain no
credentials, cookies, CSRF/authorization values, administrator email, private source, creator,
revision pointer/version, future schedule, hidden taxonomy, or fake media value.

## Review boundary

Integration/root independently reviewed the content policy, domain/service, persistence, sole
migration, API/generated contract, safe render boundary, production build, responsive screenshots,
400% reflow, Lighthouse profiles, exact-image scans, real-stack lifecycle, final health/head, and
public cleanup. There was no external-human reviewer; M14 still requires release-wide independent
review.

implementation. It does not authorize configurable pages/blocks, media storage/upload, contacts,
API tokens, audit viewer, production release, or AI runtime behavior.
