## Fresh and seeded flows

The no-seed project migrated a brand-new volume through `20260802_0005`, reconciled least-privilege
permissions, and started the final images without bootstrap or seed. Database inspection found zero
categories, skills, administrators, and seed audits. The public empty state and protected admin
redirect passed at both widths.

The separate browser project ran role initialization, migration, permission reconciliation, one
explicit fictional seed and an immediate convergent second seed, then a separate explicit
administrator bootstrap. The initial database had 2 categories and 5 skills (4 public, 1 hidden).
Full UI/API E2E created temporary data, proved hidden exclusion, reassigned and published it, changed
order, exercised filters, and deleted it. Failed harness attempts were reconverged explicitly and
left no extra catalog rows.

## Acceptance boundary

`AC-008` passes for category/skill fields, CRUD, order, filters, featured/visibility behavior,
public rendering, and the skills reference-provider contract. Links to real professional
experiences and projects remain pending the owning M5/M6 providers, exactly as the M4 dispatch
requires; no placeholder target was fabricated. This accepted boundary releases M5 work against
the stable facade and `0005` migration head.
