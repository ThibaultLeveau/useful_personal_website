## Status language

- **Accepted specification:** normative intent approved for implementation.
- **Skeleton:** navigation and invariants are useful, but executable details are not yet authoritative.
- **Implemented:** code or configuration exists and has task evidence.
- **Validated:** an independent gate record links passing evidence.

No skeleton page may be used to claim a task, milestone, or release gate has passed.
