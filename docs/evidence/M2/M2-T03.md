## Security and image corrective loop

The first final scan found 6 Critical and 18-22 High findings in the Bookworm-based images,
including OS packages without available Bookworm fixes and unused npm-tooling dependencies. This
blocked certification. Both images were moved to digest-pinned Alpine 3.23 variants while
preserving Python 3.12.13, Node 22.23.2, non-root identity, read-only operation, and healthchecks;
unused npm/corepack tooling was removed from the frontend runtime. The actual rebuilt application
images then scanned with 0 Critical/High findings and passed live probes plus the full affected
browser regression.

Other corrected defects are recorded in the task evidence: database-fixture order dependence,
probe cache headers, auth-expiry routing, screenshot focus, and shared-state E2E concurrency. No
test, scanner, type check, or coverage threshold was weakened to reach green.
