## Corrective iterations

1. Generated support files linked to deliberately disabled docs and generated
   trailing whitespace. The deterministic script now retains source only and
   formats it.
2. Generator 7.17.0's TypeScript-fetch runtime failed
   `exactOptionalPropertyTypes` and `noImplicitOverride`. Exact pattern-guarded
   post-processing repairs the types; regeneration aborts if the pinned
   template changes.
3. Generated index files emitted unused ESLint suppressions. The generator
   script removes only those index suppressions; the final lint gate has zero
   warnings.
